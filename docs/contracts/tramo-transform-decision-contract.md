# TRAMO transform decision (23-B, Unit A)

`decide_tramo_transform()` is the TRAMO pre-stage decision unit: the
`TramoUtility.calcCv` critical-value grid, the `TramoSeasonalityDetector`
machine and the `LogLevelModule` log-versus-level decision, transcribed from
the pinned jdplus 3.9.0 stack for the pre-estimation phase of `TramoKernel`.
It reports the seasonality verdict, the resulting spec flags and the
log/level outcome with both branch readouts; it does not mutate the series.
There is no Rcpp boundary; the unit is C++-only.

```cpp
kalos::TramoTransformDecisionRequest q;   // complete finite monthly series
q.mean = true; q.log_preference = std::log(0.95); q.precision = 1e-7;
auto d = kalos::decide_tramo_transform(q); // seasonality + loglevel facts
```

## Capture and corpus

`validation/evidence/native/tramo-transform/` holds the double-captured
oracle protocol (header, request echo, fact and event lines, raw IEEE-754
bits) of 26 cases run through the live pre-stage against the pinned jars
with the `--repro` byte-comparison gate. `tests/jvm_tramo_transform_decision.h`
is generated by `tools/gen_tramo_transform_golden.py`; the corpus is never
altered. The replay (10 non-robust transform cases, 6 calcCv grid points,
5 seasonality verdicts, 3 negatives/fallback gates) reproduces the live JVM
facts byte-for-byte.

## Decision laws (bytecode → unit)

- **calcCv**: `max(2.0, CriticalValueComputer.simpleComputer())` — 3.3 for
  n <= 50, the exact `3.3 + 0.0025 * (n - 50)` ramp for 50 < n < 450, 4.3
  for n >= 450; every branch exceeds the floor. A negative count throws
  (the pinned driver never asks for one).
- **Seasonality detector**: the (1 − B) differenced, mean-removed block (the
  single differenced block `DifferencingResult.of(seq, period, 1, true)`
  yields) feeds (a) the Qs Ljung-Box variant with zero-mean
  autocorrelations at the seasonal lags — two autocorrelations, positive
  ones only, the sum early-exits to exactly 0.0 when the first seasonal
  autocorrelation is non-positive — with the pinned chi2 upper tail at 2.0
  degrees of freedom, and (b) the transcribed Friedman month-rank recipe
  (midranks over the trailing whole months, chi2 at period − 1). The
  verdict ladder (pinned dcmpg thresholds): Qs p < 0.01 → Strong; both
  tests fired → Moderate; one fired or one score point → Weak; otherwise
  NotObservable with the m011 downgrade remark.
- **LogLevelModule**: both branches estimate the airline (or m011)
  fixed-order model through the qualified estimation layer — HR start with
  stabilization, the sum-of-squares Levenberg-Marquardt minimizer at the
  module precision, maximum likelihood — riding the CI-FDLIBM routing; the
  readouts are the pinned `ConcentratedLikelihoodWithMissing` pair from the
  dedicated deviances machine. The comparison is `ln(ssq * factor)` with
  the log-preference offset (`TramoSpec.log().logPreference()`, JVM default
  `Math.log(0.95)`); the meanCorrection constant column is always present
  (bytecoded-verified). Module field semantics after `clear()`: log = 1.0,
  level = 0.0, slog = 0.0, and a failed branch keeps its default exactly
  like the pinned fields.

## Fail-closed matrix

- frequency/period other than 12, non-complete or non-finite series, size
  below 2 * period: `std::invalid_argument` (register D11: monthly only).
- the robust AO+LS correction TramoKernel can run ahead of the decision is
  held by open register D3: requests that would need it are rejected, never
  approximated.
- an estimation exception on a branch maps onto the module's Failed status
  with the pinned field defaults preserved (the successful branch's
  `ln(ssq * factor)` survives).

## Implementation-actual deltas at landing (23-B Unit A)

- `AutoCovarianceFunction` ardeg == 0 branch: `SymmetricFilter.convolutionOf`
  runs over `BackFilter.weightsToArray()`, so the c[k] accumulation is
  DESCENDING in the ma index (a 1-ulp drift on the eps-probe points before
  the fix).
- `estimate_sarima_fixed` HannanRissanen start: the meanCorrection constant
  column lives on the DIFFERENCED scale (like the machine) and the
  initializer reads the differenced response from the same
  single-polynomial differenced model the machine runs on.
